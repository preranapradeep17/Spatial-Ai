## 4. Academic Viva Demonstration Map
During project examination, this matrix serves as the live evaluation roadmap:
1. **Perception**:
   - `python3 scripts/visualize_sunrgbd_labels.py` -> Show real SUN RGB-D indoor samples with 2D bounding boxes and depth overlays.
   - `python3 scripts/evaluate_detector.py` -> Demonstrate live inference of the custom detector on held-out test frames.

   - `pytest tests/test_localization.py` -> Demonstrate 0.423 m metric accuracy against ground-truth 3D physical centroids using tilt-corrected backprojection.
3. **Custom Transformer Language Model**:
   - `python3 scripts/train_language_model.py` -> Display from-scratch training convergence and autoregressive generation.
   - `cat results/metrics/transformer_training_log.json` -> Inspect perplexity drop ($304.07 \to 4.52$).

5. **Local RAG System**:
   - `pytest tests/test_rag.py` -> Show TF-IDF vectorizer retrieving override code 7391 from facility documents.
6. **Sim-to-Real Domain Transfer**:
   - `python3 scripts/evaluate_unity_transfer.py` -> Show comparative benchmark metrics between SUN RGB-D and Unity game camera.
7. **Playable 3D World & Multimodal Investigation**:
   - Open `http://localhost:8000` $\to$ Explore 5 distinct facility rooms in 3rd-person avatar mode (or 1st-person / top-down).

   - Test Mystery Selection & Flow: Click `NEW MYSTERY` to select Mystery A, B, C, D, or E; use `RESTART MISSION` or `RETURN TO HUB`.

   - Click `🔍 SYSTEM INSPECTOR` $\to$ inspect correlated execution `#corr-...` across Computer Vision (real test frame canvas overlay, depth colormap, tensor shapes, 3D detections), Computer Graphics (live player coordinates, orientation, active room, rendering stats), and LLM / Agents (token IDs, raw model output, direct generation vs fallback badge, tool call & result, RAG passages, turn latency).

   - `python3 -m pytest tests/` -> 113/113 automated tests passing cleanly (100% pass rate across perception, spatial reasoning, missions, prompt alignment, intent routing, conversational reference resolution, typographical robustness, and from-scratch transformer training).
